# Bookstore — Mobile 

Мобильное приложение **Bookstore**, разработанное на **Flutter**   
Приложение предназначено для онлайн-книжного магазина и охватывает полный пользовательский путь: от онбординга и авторизации до оформления заказа и управления профилем.

---

## Описание проекта

Bookstore Mobile — это клиентское Flutter-приложение, которое позволяет пользователям:

- просматривать каталог книг и авторов
- смотреть подробную информацию о книге
- добавлять книги в корзину
- оформлять заказы
- управлять избранным
- работать с профилем и адресами
- проходить онбординг и авторизацию

Приложение построено с использованием **feature-based архитектуры**, **BLoC** для управления состоянием и разделением на `core`, `features` и `shared`.

---

## Основная функциональность

- Главная страница с подборками книг и авторов  
- Авторизация и регистрация  
- Онбординг и splash-экран  
- Детальная страница книги  
- Корзина и оформление заказа  
- Избранные книги  
- Работа с локацией пользователя  
- Профиль пользователя и заказы  

---

## Используемые технологии

- **Flutter**
- **Dart**
- **BLoC / State Management**
- **REST API**
- **Dependency Injection**

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/fpmi-hci-2025/project13-mobile-bookstore.git
cd project13-mobile-bookstore
````

2. Установить зависимости:

```bash
flutter pub get
```

3. Запустить приложение:

```bash
flutter run
```

## Структура проекта

```
lib/
├── main.dart                 # Точка входа в приложение
├── app_initializer.dart      # Инициализация зависимостей и сервисов
├── firebase_options.dart     # Конфигурация Firebase
│
├── core/                     # Базовая инфраструктура приложения
│   ├── api/                  # API клиенты и репозитории
│   ├── bloc/                 # Общие bloc-провайдеры
│   ├── config/               # Конфигурация и роутинг
│   ├── di/                   # Dependency Injection
│   ├── formatter/            # Форматирование данных
│   ├── models/               # Доменные модели
│   ├── route/                # Навигация и маршруты
│   ├── services/             # Сервисы (локация и др.)
│   └── storage/              # Локальное хранилище
│
├── features/                 # Фичи приложения
│   ├── auth/                 # Авторизация
│   ├── onboarding/           # Онбординг
│   ├── registration/         # Регистрация
│   ├── splash/               # Splash экран
│   ├── home/                 # Главный экран и связанные разделы
│   │   ├── book_detail/      # Детальная страница книги
│   │   ├── author/           # Страница автора
│   │   ├── cart/             # Корзина
│   │   ├── category/         # Категории
│   │   ├── navigation/       # Нижняя навигация
│   │   └── profile/          # Профиль пользователя
│   └── location/             # Работа с локацией
│
├── shared/                   # Переиспользуемые элементы
│   ├── components/           # UI-компоненты
│   ├── constants/            # Константы
│   ├── theme/                # Цвета, темы, типографика
│   └── widgets/              # Общие виджеты
```
